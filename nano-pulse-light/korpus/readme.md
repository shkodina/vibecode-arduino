# Корпус фонаря nano-pulse-light

Обтекаемый корпус домашнего фонаря: скруглённые рёбра, ручка сверху,
аккумулятор SF 12045 вынимается сзади, на верхней грани — питание, режимы
и окно датчика пульса.

## Какие файлы

Печатные детали — по файлу на каждую, как STL так и DAE:

| Деталь | STL (слайсер) | DAE (SketchUp Pro 2022) |
|--------|----------------|-------------------------|
| основа с ручкой и окнами | `stl/korpus.stl` | `dae/korpus.dae` |
| дверь + лоток аккумулятора | `stl/vyemnyy_blok.stl` | `dae/vyemnyy_blok.dae` |
| габарит SF 12045, **не печатать** | `stl/SF_12045_ne_pechatat.stl` | `dae/SF_12045_ne_pechatat.dae` |

`korpus_fonarya.rb` только импортирует три DAE в пустой файл SketchUp.
Размеры и форма считаются в `sdelat_korpus.py`.

## Как устроено

Корпус — скруглённый брусок 124 × 158 × 94 мм, радиус скругления 12 мм.
Передняя грань самая большая: тонкий рассеиватель и шесть каналов под
ленту 10 мм.

Сверху сзади — дуговая **ручка** (трубка Ø22 мм, внутри ~34 мм под пальцы).
На верхней грани, ближе к световой стороне, слева направо:

| Что | Посадка | Клеммы | Координаты X, Y от левого переднего угла верха |
|-----|---------|--------|-----------------------------------------------|
| Питание, цилиндр | Ø14 мм, глубина 12 мм | ещё 6 мм вниз | 28, 28 |
| Режимы, квадрат | 13.5 × 13.5 мм, глубина 12 мм | ещё 6 мм вниз | 58, 28 |
| Пульс HW827 | окно Ø16 мм, палец кладётся сверху | карман 22×18×8 мм изнутри | 96, 28 |

Отверстия сквозные: кнопка садится на 12 мм, за ней воздух под пайку.
Датчик смотрит наружу через окно 16 мм — палец закрывает площадку.

Сзади вынимается блок: скруглённая дверь, лоток под батарею, петля чтобы
тянуть. **Четыре винта M3** по углам, 10 мм от края:

- в двери отверстие 3.3 мм насквозь;
- в бобышках корпуса 2.5 мм × 8 мм (саморез в PLA).

```text
              ручка
           ===========
     +-------------------+
     | (пит) (реж) (пульс)|  верх, органы
     |                   |
     |      СВЕТИТ       |  перед 124 x 158
     |                   |
     +-------------------+
              (M3)   петля ->  выемный блок
```

## SketchUp Pro 2022

1. Новый пустой файл, единицы миллиметры.
2. Либо File → Import по очереди три файла из `dae/`.
3. Либо Ruby Console:

```ruby
load '/home/blobby/home_cnf/xtmp-work-dir/vibecode-arduino/nano-pulse-light/korpus/korpus_fonarya.rb'
```

4. File → Save As → `korpus_fonarya.skp`.

DAE весит десятки мегабайт — это сглаженная сетка. Импорт может занять
минуту. Для печати DAE не нужен, бери STL.

## Печать

PLA, сопло 0.2 мм (0.4 мм будет быстрее и не хуже по прочности).

| Параметр | Значение |
|----------|----------|
| Слой | 0.12 мм при сопле 0.2 |
| Стенки | ≥ 2.6 мм |
| Заполнение | 25–30% гироид, у ручки 40% |
| Рассеиватель | первые ~1 мм основы 100%, белый PLA |
| Стол / сопло | 60 / 205 °C |
| Кайма | да |

Ориентация:

- **korpus** — передней светящейся гранью на стол (124 × 158 вниз).
  Ручка окажется у дальнего края стола, в плоскости стола, без поддержек
  на дуге. Спина открыта вверх.
- **vyemnyy_blok** — внутренней стороной двери на стол. Лоток растёт вверх,
  петля — тоже вверх.

Стол Creality 220 × 220: основа ~124 × 203 мм (с ручкой по высоте грани),
влезает.

## Сборка

1. Лента 10 мм в шесть каналов изнутри переда.
2. Кнопка питания Ø14 — сверху слева, гайка/клипса с внутренней бобышки.
3. Квадрат 13.5 мм — рядом, режимы.
4. HW827 — в карман под окном 16 мм, площадкой к отверстию, чтобы палец
   её видел/закрывал.
5. Nano и IRF520 — на полке над аккумулятором. Провода клемм F1 через щель
   в полке.
6. Аккумулятор в лоток, блок задвинуть, четыре M3.
