# nano-pulse-light

Светодиодная лента, которая дышит в ритм пульса. Arduino Nano читает датчик
HW827, считает удары в минуту и качает яркость 12-вольтовой ленты через
MOSFET IRF520. Кнопкой переключаются яркость, метроном, стробоскоп и таймер
сна.

Рядом в этой же папке лежит `lolin-web-pulse` — тот же детектор ударов, но
картинка была в браузере. Здесь картинка — сама лента, без wifi.

## Идея и цель

Хотелось «живую» подсветку без экрана: приложил палец к датчику — лента
разгорается и гаснет вместе с сердцем. Без пальца она не сбрасывается на
дефолт, а продолжает тот темп, который уже набрала. При включении специально
идёт очень медленная качка (20 уд/мин): сразу видно, что живого пульса ещё
нет.

Цель такая:

- режим 1 — лента дышит в пульс, от 10% до 100% яркости;
- одной кнопкой — фиксированная яркость, выключение, метроном, стробоскоп;
- двойное нажатие — через 10 минут всё гасится, контроллер засыпает;
- все числа (пины, темп, яркости, частота строба) лежат в одном `config.h`.

## Концепт решения

Всё крутится на одной Nano в одном цикле `loop`, без операционки и без wifi.

**Датчик** отдаёт аналоговую волну на `A0`. Скетч 200 раз в секунду ищет в
ней удары и считает пульс по скользящему окну 10 секунд.

**Лента** сидит на 12 В, Nano её не питает. Nano только даёт ШИМ на вход
IRF520 (`D11` — это аппаратный PWM, на `D12` его нет). Яркость не прыгает
на каждый удар: фаза качки копится плавно. Иначе при смене уд/мин лента
вспыхивала бы рывками.

**Кнопка** — нормально замкнутая, между `D2` и землёй, без резистора. На Nano
есть внутренний подтяг к +5 В. В покое контакты замкнуты, пин сидит на земле
(LOW). Нажали — разомкнулись, подтяг тянет пин вверх (HIGH). Из глубокого сна
будит прерывание смены уровня на том же `D2`.

Почему не вешать кнопку на 5 В: у ATmega328P нет внутреннего подтяга к земле.
Без внешнего резистора пин при размыкании повис бы в воздухе.

## Что делает прошивка

После включения — режим пульса, темп 20 уд/мин (маркер «ещё не меряли»).

Когда пальца нет, лента продолжает последний нормальный темп, а не скачет
на 20. На 20 сбрасывается только при питании и после сна.

Живой пульс принимается только в диапазоне **40…140 уд/мин**. Что ниже или
выше — считаем невозможным, цифру не обновляем.

Кнопка (считаем после паузы 450 мс с последнего отпускания):

| Нажатия | Что происходит |
|---------|----------------|
| 1 | Листает режимы 1→2→…→7→1. Если был метроном или строб — только выключает их, режим не трогает. |
| 2 | Обратный таймер 10 минут. Режим свечения не меняется. Потом лента гаснет, Nano засыпает. Будит то же нажатие, старт как после питания. |
| 3 | Метроном: плавная качка раз в секунду, 10%…100%. |
| 4 | Стробоскоп: резко 0% / 100%. |

Режимы одинарного клика:

1. пульс;
2. 20% яркости;
3. 40%;
4. 60%;
5. 80%;
6. 100%;
7. лента выключена.

Метроном и стробоскоп — наложения поверх текущего режима, не пункты круга 1…7.

## Схема подключения

```text
                     Arduino Nano
                    +-------------+
     HW827 VCC -----+ 5V          |
     HW827 GND -----+ GND         |
     HW827 S   -----+ A0          |
                    |             |
     кнопка NC -----+ D2          |
         |          |             |
         +----------+ GND         |
                    |             |
     IRF520 SIG ----+ D11 (PWM)   |
     IRF520 GND ----+ GND         |     земля логики общая
                    |             |
                    | USB (COM)   |
                    +------+------+
                           |
                        питание Nano

     лента 12 В ---- IRF520 нагрузка (VIN / OUT модуля)
     блок 12 В  ---- IRF520 питание ленты, GND блока — к GND модуля
```

Железные ограничения, которые уже учтены:

1. Управление лентой — **D11**, не D12. На Nano ШИМ есть на D3, D5, D6, D9,
   D10, D11. На D12 `analogWrite` не работает.
2. Датчик питаем от **5 В**. На Lolin было 3.3 В, здесь АЦП 0…1023 от 5 В,
   шума меньше. Пороги детектора всё равно можно подкрутить.
3. Кнопка — **NC между D2 и GND**, резистор не нужен.
4. 12 В ленты через MOSFET, не с пина Nano. После сна MOSFET закрыт, лента
   тёмная.
5. «Глубокий сон» глушит сам ATmega. USB-чип CH340 на клонах всё равно ест
   ток — для ленты это не важно.

## Как считается пульс

Детектор тот же, что в `lolin-web-pulse`. Сырой порог «больше числа — удар»
на HW827 врёт из-за дыхания и прижима пальца, поэтому шаги такие:

1. **Сглаживание** — убрать шум АЦП (~100 мс).
2. **Базовая линия** — медленный уровень (~1.5 с), вычитаем его. Волна
   качается вокруг нуля.
3. **Сила волны** — среднеквадратичное (~3 с), не максимум. Рывок пальцем
   меньше портит порог.
4. **Удар** — волна снизу вверх через 0.9 силы. Следующий удар ловим только
   после спада до 0.3 силы.
5. **Короткий промежуток** — вторичный пик волны, не удар. Иногда всё равно
   пролезает: тогда цифра получается примерно вдвое больше настоящей.
6. **Окно 10 с** — от первого удара окно растёт, потом едет следом.
   Пульс = (число ударов − 1) × 60000 / время между первым и последним
   ударом в окне.
7. **40…140** — вне этого диапазона цифру не пишем.

Если сила волны меньше `MIN_SILA` — пальца нет. Детектор сбрасывается, лента
остаётся в последнем темпе.

## Файлы проекта

```text
nano-pulse-light/
  nano-pulse-light.ino   логика: датчик, лента, кнопка, сон
  config.h               все константы, это главное место правок
  sborka.sh              сборка и заливка
  .env.primer            пример настроек порта
  .env                   твои PORT / REZHIM / PLATA (в git не попадает)
  prompt                 исходное задание
  readme.md              этот файл
```

`nano-pulse-light.ino` читается сверху вниз примерно так:

- обработка сигнала и окно ударов;
- яркость ленты (плавная качка, строб);
- режимы и кнопка (1…4 клика);
- таймер и сон;
- `setup` / `loop`.

Библиотек ставить не надо. Нужны только ядро AVR и заголовки `avr/sleep.h`,
они входят в пакет `arduino:avr`.

## Что где править

Почти всё — в `config.h`. Скетч трогать не обязательно.

### Пины

| Константа | Сейчас | Смысл |
|-----------|--------|--------|
| `NOZHKA_DATCHIKA` | `A0` | сигнал HW827 |
| `NOZHKA_KNOPKI` | `2` | кнопка |
| `NOZHKA_LENTY` | `11` | ШИМ на IRF520 |
| `UROVEN_NAZHATIYA` | `HIGH` | нажатие = разомкнули NC на землю |

Если перенесёшь ленту на другой PWM-пин — поменяй `NOZHKA_LENTY`.

### Пульс и яркость качки

| Константа | Сейчас | Когда крутить |
|-----------|--------|----------------|
| `STARTOVYY_PULS` | 20 | медленный маркер при включении |
| `MIN_PULS` / `MAX_PULS` | 40 / 140 | что считать невозможным |
| `OKNO_PULSA_MS` | 10000 | длина окна подсчёта |
| `MIN_YARKOST_PULSA_PROCENT` | 10 | пол качки в режиме пульса |
| `MAX_YARKOST_PULSA_PROCENT` | 100 | потолок качки |
| `YARKOST_REZHIM_2_PROCENT` … `_6_` | 20…100 | фиксированные режимы |

Если детектор врёт (нет ударов при пальце, или наоборот шумит):

1. смотри монитор порта, строка `sila=…`;
2. пальца нет, а `sila` уже больше 1 — подними `MIN_SILA`;
3. палец есть, ударов нет — опусти `MIN_SILA` или `POROG_V_SILAH`;
4. пульс стабильно вдвое больше настоящего — уменьши `MIN_DOLYA_OT_SREDNEGO`
   (сейчас 0.55), чтобы жёстче отсекать второй зубец волны.

### Метроном, строб, кнопка, сон

| Константа | Сейчас | Смысл |
|-----------|--------|--------|
| `METRONOM_PERIOD_MS` | 1000 | период метронома |
| `METRONOM_MIN_PROCENT` / `_MAX_` | 10 / 100 | пол и потолок метронома |
| `STROB_PERIOD_MS` | 80 | полный цикл вспышка+пауза (~12.5 вспышек/с) |
| `STROB_MIN_PROCENT` / `_MAX_` | 0 / 100 | строб резко 0/100 |
| `TAYMER_SNA_MS` | 10 минут | двойной клик |
| `PAUZA_KLIKOV_MS` | 450 | пауза, после которой считаем 1/2/3/4 клика |
| `ANTIDREBEZG_MS` | 40 | антидребезг кнопки |

Стробоскоп: меньше `STROB_PERIOD_MS` — злее. `50` ≈ 20 Гц, `100` ≈ 10 Гц,
`200` ≈ 5 Гц.

После правки `config.h` снова `./sborka.sh zalit`.

## Сборка и заливка

Плата — Arduino Nano, ядро `arduino:avr`. Дешёвые клоны с CH340 чаще со
**старым** загрузчиком: `arduino:avr:nano:cpu=atmega328old`. Если avrdude
не связывается — в `.env` поставь новый: `cpu=atmega328`.

Один раз завести настройки:

```bash
cd /home/blobby/home_cnf/xtmp-work-dir/vibecode-arduino/nano-pulse-light
cp .env.primer .env
```

В `.env` сейчас так:

```ini
PORT=COM4
REZHIM=wsl
```

Дальше:

```bash
./sborka.sh           # только собрать
./sborka.sh zalit     # собрать и залить
```

Перед заливкой закрой Arduino IDE и монитор порта в Windows — иначе COM4
занят, заливка не пройдёт.

### Если работаем из WSL

На этой машине WSL1, COM-порт Windows виден как `/dev/ttyS*`, но надёжнее
лить виндовым `arduino-cli.exe` из Arduino IDE. Скрипт при `REZHIM=wsl`:

1. копирует `nano-pulse-light.ino` и `config.h` в
   `C:\Users\<ты>\arduino-wsl\nano-pulse-light`;
2. собирает и заливает оттуда.

COM4 в WSL это `/dev/ttyS3`. Подробности — в
`READ-ME-NOTES/arduino/wsl.md`.

### Обычный Linux, без WSL

В `.env`:

```ini
REZHIM=linux
PORT=/dev/ttyUSB0
```

Нужен `arduino-cli` и ядро:

```bash
arduino-cli core update-index
arduino-cli core install arduino:avr
```

Потом тот же `./sborka.sh zalit`.

## Монитор порта

Скорость **115200**. Раз в секунду строка вроде:

```text
pulse=72 sila=2.4 rezhim=1 metro=0 strob=0 taymer=-
```

- `pulse` — текущий темп ленты (20 сразу после включения);
- `sila` — сила волны, по ней видно, есть ли палец;
- `rezhim` — 1…7;
- `metro` / `strob` — наложения;
- `taymer` — сколько секунд осталось, или `-`.

При смене режима, метронома, строба и сна печатаются отдельные строки.

## Известные особенности

- Пульс иногда показывает примерно вдвое больше настоящего: детектор ловит
  второй зубец волны. Жить можно, лечится `MIN_DOLYA_OT_SREDNEGO` в `config.h`.
- После сна USB-чип клона всё ещё питается. Экономия — в выключенной ленте,
  не в миллиамперах самой Nano.
- Стробоскоп может быть тяжёлым для глаз. Частоту меняй `STROB_PERIOD_MS`.
